# Local run outputs

New simulator runs and generated test outputs in this directory are ignored by Git. The published Astra versus Opus episodes, camera videos and figures are in [loho-study/](../loho-study/).

- [luna_wsl_smoke/summary.json](luna_wsl_smoke/summary.json) is the unchanged historical prompt fixture read by `scripts/test_proprioception.py`. Its old camera frames are not required by the test and are not included.
- [removed_run_costs.json](removed_run_costs.json) preserves the incurred-cost receipt excluded from the retained comparison scores.

Older pilot and test artifacts were archived locally with SHA-256 checks before removal from the publishable tree.
